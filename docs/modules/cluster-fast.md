# `cluster-fast`

```{image} ../_static/figures/cluster-fast.svg
:width: 550
:class: no-scaled-link
:align: center
```

The vOTU clustering module identifies viral operational taxonomic units (vOTUs) by clustering vContigs using one of two primary methods based on user requirements: the default fast clustering protocol—which utilizes CheckV’s MEGABLAST-based approach (enabled by `clustering-fast`)—or the more sensitive, though computationally intensive, CD-HIT approach (enabled by `clustering-sensitive`). To ensure biological consistency and standardized taxonomic resolution, both methods adhere to the Minimum Information about an Uncultivated Virus Genome (MIUViG) guidelines, requiring a minimum of 95% average nucleotide identity and 85% alignment coverage.

## Quick Run

::::{tab-set}
:::{tab-item} Single Fasta

```bash
# Conda Run
snakemake --sdm conda --use-conda --config module="cluster-fast" fasta="sample/contigs/contigs_simulated_viral_nonviral.fasta" outdir="sample/results" -j 4 --latency-wait 20

# Apptainer (Docker Image)
snakemake --sdm conda apptainer --config module="cluster-fast" fasta="sample/contigs/contigs_simulated_viral_nonviral.fasta" outdir="sample/results" -j 4 --latency-wait 20
```

## Configuration

- **`clustering-fast`:** Flag to run fast clustering using CheckV's MEGABLAST approach. If set to False, CD-HIT will be used. Proceed with caution as it can be extremely slow at large sequence numbers || (default: True)
- **`cdhit-params`:** Additional parameters to pass on to CD-HIT if clustering-fast is set to False <https://github.com/weizhongli/cdhit/blob/master/doc/cdhit-user-guide.wiki> || (default: "-c 0.95 -aS 0.85 -d 400 -M 0 -n 5")
- **`vOTU-ani`:** Minimum average nucleotide identity for fast clustering algorithm of viral contigs || default: 95
- **`vOTU-targetcov`:** Minimum target coverage for fast clustering algorithm of viral contigs || (default: 85)
- **`vOTU-querycov`:** Minimum query coverage for fast clustering algorithm of viral contigs || (default: 0)

## Outputs

```bash
identify/viral/output/derep
├── cluster_representatives.txt
├── clusters.tsv
└── combined.viralcontigs.derep.fa
```

The main output from this module is the assembly file `final.contigs.fa` which includes the final contigs generated by `megahit` or `SPAdes`. These contigs will be used for many steps in downstream analysis.
