# `viral-end-to-end`

```{image} ../_static/figures/viral-end-to-end.svg
:width: 550
:class: no-scaled-link
:align: center
```

For users seeking a completely automated, "reads-to-insights" solution, the `viral-end-to-end` module executes the entire vOMIX-MEGA ecosystem in a single unified execution wrapper. This master workflow streamlines data handling, eliminates manual intermediate file handling, and runs the following core modules sequentially:

1. **`preprocess`**: Cleans, trims, and filters raw fastq reads.
2. **`assembly`**: Assembles the clean reads into contigs.
3. **`viral-identify`**: Screens, clusters, and evaluates sequences to build the core vOTU database.
4. **`viral-taxonomy`**: Assigns phylogenetically sound taxonomic lineages to the vOTUs.
5. **`viral-host`**: Connects viral sequences to predicted cellular hosts using network and CRISPR matching.
6. **`viral-annotate`**: Runs protein-level gene prediction and multi-database functional profiling.
7. **`viral-community`**: Maps reads back to vOTUs to output comprehensive RPKM and TPM abundance profiles.

## Quick Run

::::{tab-set}
:::{tab-item} Sample List

```bash
# Conda Run
snakemake --config module="viral-end-to-end" outdir="sample/results" datadir="sample/fastq" samplelist="sample/sample_list.csv" --sdm conda --use-conda -j 4 --latency-wait 20

# Apptainer (Docker Image)
snakemake --config module="viral-end-to-end" outdir="sample/results" datadir="sample/fastq" samplelist="sample/sample_list.csv" --sdm apptainer --use-conda -j 4 --latency-wait 20
```

:::
::::

``` {admonition} Dry Run
:class: Tip
Use the `-n` flag with your command to perform a dry-run first, listing all analyses that will be performed.
```

## Configuration

- **`humann-params`:** Additional software parameters directed to the HUMAnN functional annotation pipeline. (default: "--remove-temp-output")

## Outputs

```bash
results
├── preprocess
├── assembly
    ├── megahit
    └── spades
├── identify
    └── viral
├── taxonomy
    └── viral
├── community
    └── viral
├── host
└── annotate
    └── viral
```

The main output from this module is the assembly file `final.contigs.fa` which includes the final contigs generated by `megahit` or `SPAdes`. These contigs will be used for many steps in downstream analysis.
