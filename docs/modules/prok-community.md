# `prok-community`

```{image} ../_static/figures/prok-community.svg
:width: 550
:class: no-scaled-link
:align: center
```

The `prok-community` module functions as an integrated Snakemake workflow designed to automate the prokaryotic community profiling process. By serving as a specialized wrapper around `MetaPhlAn v4`, this module simplifies the end-to-end management of database maintenance, software environment configuration, and taxonomic quantification. Upon execution, it performs community profiling in strict accordance with the standard MetaPhlAn protocol, subsequently processing the raw results to produce stratified abundance tables across various taxonomic levels. This structured output facilitates the rapid assessment of microbial community composition and taxonomic shifts across diverse metagenomic samples.

## Quick Run

::::{tab-set}
:::{tab-item} Sample List

```bash
# Conda Run
snakemake --config module="prok-community" outdir="sample/results" datadir="sample/fastq" samplelist="sample/sample_list.csv" --sdm conda --use-conda -j 4 --latency-wait 20

# Apptainer (Docker Image)
snakemake --config module="prok-community" outdir="sample/results" datadir="sample/fastq" samplelist="sample/sample_list.csv" --sdm apptainer --use-conda -j 4 --latency-wait 20
```

:::
::::

``` {admonition} Dry Run
:class: Tip
Use the `-n` flag with your command to perform a dry-run first, listing all analyses that will be performed 
```

## Configuration

- **`mpa-params`:** Parameters for metaphlan function <https://huttenhower.sph.harvard.edu/metaphlan/> || (default: "--ignore_eukaryotes")
- **`mpa-indexv`:** Database version for metaphlan to use <https://huttenhower.sph.harvard.edu/metaphlan/> || (default: "mpa_vOct22_CHOCOPhlAnSGB_202212")

## Outputs

```bash
community/metaphlan
├── output
    ├── metaphlan_out_SGB.txt
    ├── metaphlan_out_species.txt
    ├── metaphlan_out_genus.txt
    ├── metaphlan_out_family.txt
    ├── metaphlan_out_order.txt
    ├── metaphlan_out_class.txt   
    ├── metaphlan_out_phylum.txt
    └── metaphlan_out.txt
├── samples
├── logs
├── benchmarks
└── tmp
```

The main output from this module is the assembly file `final.contigs.fa` which includes the final contigs generated by `megahit` or `SPAdes`. These contigs will be used for many steps in downstream analysis.
